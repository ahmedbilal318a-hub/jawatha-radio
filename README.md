# استبيان تقييم الإذاعة المدرسية — مدارس جواثا الأهلية

موقع صفحة واحدة يقيّم فيه المعلمون الإذاعة الصباحية على عشرة معايير، كل معيار من ١٠ درجات
(٢ · ٤ · ٦ · ٨ · ١٠)، والمجموع من ١٠٠. وللمشرف لوحة نتائج تحسب المتوسط العام وتعرض درجات كل معلم.

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | الموقع كامل، صفحة واحدة بلا أي اعتمادات |
| `apps-script/Code.gs` | كود جوجل Apps Script الذي يحفظ التقييمات في ملف جوجل شيت |

## الربط بجوجل شيت (مرة واحدة)

1. أنشئ ملف Google Sheets جديدًا باسم «تقييم الإذاعة».
2. من قائمة **Extensions** اختر **Apps Script**.
3. امسح الكود الموجود، والصق محتوى `apps-script/Code.gs`.
4. غيّر السطر `var ADMIN_KEY = 'jawatha2026';` إلى رمز من اختيارك — هذا رمز دخول لوحة النتائج.
5. احفظ، ثم **Deploy ← New deployment ← Web app**، واضبط:
   - Execute as: **Me**
   - Who has access: **Anyone**
6. انسخ رابط التطبيق المنتهي بـ `/exec`.
7. في `index.html` ضع الرابط داخل المتغير `API` في أول سكربت الصفحة:

```js
var API='https://script.google.com/macros/s/..../exec';
```

## النشر على GitHub Pages

الريبو منشور بالفعل عبر GitHub Pages من الفرع `main` والمجلد الجذر.
أي تعديل يُرفع على `main` يظهر على الموقع خلال دقيقة تقريبًا.

## كيف يعمل الموقع

- المعلم يكتب اسمه وتاريخ الإذاعة وعنوانها، ويقيّم المعايير العشرة، ويرسل.
  يرى مجموعه من ١٠٠ وتقديره، ويستطيع تعديل تقييمه في نفس اليوم.
- التقييم يُرسل إلى جوجل شيت، وتُحفظ نسخة منه على جهاز المعلم ليرى نتيجته.
- المشرف يضغط «دخول المشرف» أسفل الصفحة ويدخل الرمز، فتظهر له لوحة النتائج:
  المتوسط العام من ١٠٠، التقدير، عدد المقيّمين، متوسط كل معيار، درجات كل معلم بالتفصيل،
  سجل الأيام، وتنزيل النتائج كملف Excel.
- المعلم لا يرى لوحة النتائج، والقراءة من السجل محمية بالرمز في Apps Script نفسه.

# استبيان تقييم الإذاعة المدرسية — مدارس جواثا الأهلية

موقع صفحة واحدة يقيّم فيه المعلمون الإذاعة الصباحية على عشرة معايير، كل معيار من ١٠ درجات
(٢ · ٤ · ٦ · ٨ · ١٠)، والمجموع من ١٠٠، مع لوحة نتائج للمشرف تحسب المتوسط العام.

لا يحتاج الموقع إلى خادم ولا قاعدة بيانات ولا أي حساب: التقييم ينتقل من المعلم إلى المشرف
على هيئة **رمز تقييم** قصير.

## كيف يعمل

**الطريقة الأساسية: جهاز واحد يدور على المعلمين**

1. افتح الموقع على جهاز واحد (جوال أو لابتوب) واكتب تاريخ الإذاعة وعنوانها.
2. كل معلم يكتب اسمه (المعلم المقيِّم) والفصل المقيَّم، يقيّم المعايير العشرة، ويضغط «اعتماد التقييم» فيرى مجموعه وتقديره.
3. يضغط «معلم جديد» فيجهز الاستبيان للتالي. التقييم محفوظ على الجهاز فورًا.
4. المشرف يضغط «دخول المشرف» أسفل الصفحة ويدخل الرمز (`jawatha` افتراضيًا — غيّره من أول سطر
   في سكربت الصفحة)، فيرى كل معلم ودرجته، وعند الضغط على الاسم تظهر درجاته في المعايير العشرة
   وملاحظاته، ومعها الخلاصة ومتوسط كل معيار وسجل الأيام وتنزيل النتائج كملف Excel.

**إذا قيّم معلم من جواله**

بعد اعتماد التقييم يفتح «المعلم قيّم من جواله؟» ويضغط «مشاركة النتيجة» فيختار أي تطبيق،
أو ينسخ الرابط أو الرمز. المشرف يفتح الرابط فتُضاف النتيجة عنده تلقائيًا، أو يلصق الرمز
في صندوق «إضافة رموز المعلمين» أسفل لوحة النتائج.

تقييم المعلم نفسه لا يُحسب مرتين: الرمز مرتبط بالاسم والتاريخ، فإعادة إرسال نفس المعلم في نفس
اليوم تُحدِّث تقييمه بدل أن تضيفه من جديد.

## شكل الرمز

```
JW1|2026-10-24|4534543454|أحمد بلال|إذاعة عن بر الوالدين|أداء ممتاز|السادس / أ
```

بالترتيب: علامة النظام، تاريخ الإذاعة، عشرة أرقام تمثّل درجات المعايير (١ تعني ٢ درجات و٥ تعني ١٠)،
ثم اسم المعلم المقيِّم، فعنوان الإذاعة، فالملاحظات، فالفصل المقيَّم (أُضيف آخرًا حتى تبقى الرموز القديمة صالحة).

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | الموقع كامل، صفحة واحدة بلا أي اعتمادات خارجية عدا الخطوط |
| `apps-script/Code.gs` | اختياري ومؤجَّل: ربط التقييمات بجوجل شيت بدل الرموز |
| `apps-script/Code-standalone.gs` | نفس السابق لكنه يفتح ملف الشيت برقمه دون ربط |

ملفا Apps Script محفوظان للمستقبل فقط؛ الموقع الحالي لا يستعملهما ولا يحتاج إليهما.

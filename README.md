# استبيان تقييم الإذاعة المدرسية — مدارس جواثا الأهلية

موقع صفحة واحدة يقيّم فيه المعلمون الإذاعة الصباحية على عشرة معايير، كل معيار من ١٠ درجات
(٢ · ٤ · ٦ · ٨ · ١٠)، والمجموع من ١٠٠، مع لوحة نتائج للمشرف تحسب المتوسط العام.

كل تقييم يُرسل تلقائيًا إلى جوجل شيت من أي جوال، ولوحة المشرف تقرأ منه وتعلن عن كل تقييم جديد لحظة وصوله.

## كيف يعمل

1. كل معلم يفتح الموقع من جواله (أو من جهاز واحد يدور عليهم)، ويكتب اسمه (المعلم المقيِّم) والفصل المقيَّم
   وتاريخ الإذاعة وعنوانها، ويقيّم المعايير العشرة، ويضغط «اعتماد التقييم».
2. التقييم يُرسل إلى الشيت فورًا؛ وإن لم يتوفر إنترنت يُحفظ على الجوال ويُرسل عند الاتصال.
3. المشرف يضغط «دخول المشرف» أسفل الصفحة ويدخل الرمز، فيرى المتوسط العام بالنجوم ورمز التقدير،
   وكل معلم ودرجاته وملاحظاته، ومتوسط كل معيار وسجل الأيام، وتنزيل النتائج كملف Excel.
4. اللوحة تتحدّث كل نصف دقيقة؛ وعند وصول تقييم جديد يظهر إشعار 🎉 باسم المعلم ودرجته،
   ويتحرك المتوسط إلى قيمته الجديدة، ويُبرَز كرت المعلم الجديد.

تقييم المعلم نفسه لا يُحسب مرتين: التقييم مرتبط بالاسم والتاريخ، فإعادة إرسال نفس المعلم في نفس
اليوم تُحدِّث تقييمه بدل أن تضيفه من جديد.

## روابط التقييم القديمة

الروابط القديمة بصيغة `#r=` (من قبل الربط بالشيت) ما زالت تُقرأ عند فتحها كمشرف:

```
JW1|2026-10-24|4534543454|أحمد بلال|إذاعة عن بر الوالدين|أداء ممتاز|السادس / أ
```

بالترتيب: علامة النظام، تاريخ الإذاعة، عشرة أرقام تمثّل درجات المعايير (١ تعني ٢ درجات و٥ تعني ١٠)،
ثم اسم المعلم المقيِّم، فعنوان الإذاعة، فالملاحظات، فالفصل المقيَّم.

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | الموقع كامل، صفحة واحدة بلا أي اعتمادات خارجية عدا الخطوط |
| `apps-script/Code.gs` | ربط التقييمات بجوجل شيت (يُلصق داخل ملف الشيت) |
| `apps-script/Code-standalone.gs` | نفس السابق لكنه يفتح ملف الشيت برقمه دون ربط |

## التجميع التلقائي عبر جوجل شيت

إذا وُضع رابط تطبيق Apps Script (المنتهي بـ `/exec`) في المتغير `API` أعلى سكربت `index.html`،
يُرسل كل تقييم إلى الشيت تلقائيًا من أي جوال، ولوحة المشرف تقرأ كل التقييمات منه وتحدّث نفسها كل نصف دقيقة.
التقييم الذي لم يُرسل لغياب الإنترنت يبقى محفوظًا ويُعاد إرساله عند الاتصال.
يُكتب رمز دخول المشرف في `ADMIN_KEY` داخل Apps Script فقط، ولا يُرفع إلى GitHub.
إذا بقي `API` فارغًا يعمل الموقع بالجهاز الواحد والرموز كما سبق.

## النشر

منشور عبر GitHub Pages من الفرع `main` والمجلد الجذر. أي تعديل يُرفع على `main` يظهر خلال دقيقة.
